# 🚗 Avto-Ijara — Avtomobillarni ijaraga berish veb-sayti

React va Vite asosida yaratilgan zamonaviy, tezkor avto-ijara veb-ilovasi.

## 🌟 Asosiy imkoniyatlar:
- **Bosh sahifa (`/`)**: Barcha, VIP va Standart avtomobillar bo'limlari, qulay filter tizimi.
- **❤️ Sevimlilar**: Mashinalarni yoqtirish (Like) va ularni saqlash (`localStorage`).
- **Avtomobil sahifasi (`/car/:id`)**: Mashina haqida to'liq ma'lumot, o'rindiqlar soni, ijara kunlarini tanlash (`−` va `+`) hamda narxni bir zumda qayta hisoblash.
- **Mening ijaralarim (`/bookings`)**: Ijaraga olingan mashinalar ro'yxati, kunlar va umumiy summa hisobi.
- **25+ xil avtomobil**: Bugatti Chiron, Rolls-Royce Ghost, Ferrari F8, Lamborghini Urus, BMW M5 F90, Tahoe, Malibu 2, Cobalt, Gentra, Onix, Matiz va boshqalar o'zining haqiqiy fotosuratlari bilan.

## 🚀 Loyihani ishga tushirish:
```bash
# Kerakli paketlarni o'rnatish
npm install

# Dasturchi rejimida ishga tushirish
npm run dev

# Loyihani yig'ish (build)
npm run build
```

## 🛠 Texnologiyalar:
- **React 19**
- **Vite**
- **React Router DOM**
